# CISR Global HRMS

## System Overview

The CISR Global HRMS (Human Resource Management System) is designed to streamline human resource processes and improve organizational efficiency. This system includes capabilities for employee management, payroll, recruitment, and performance monitoring.

## Features
- Employee Management
- Payroll Processing
- Recruitment Tracking
- Performance Monitoring

## Technologies Used
- Frontend: React
- Backend: Node.js
- Database: MongoDB

## Getting Started
1. Clone the repository
2. Install dependencies
3. Configure the environment variables
4. Run the application
